# AI Account Switcher v0.7.2

This release adds project-level token and cost reporting for Claude Code and Codex, with detailed
drill-downs that stay responsive on large local usage histories.

## What Changed

- Added a dedicated **Projects** view inside Usage with combined, Claude, and Codex filters.
- Grouped local token usage by the absolute working folder recorded in each CLI session.
- Added token totals, estimated cost, session count, and last activity for every project.
- Added an expandable full-width report per project with daily trends, model breakdowns, and recent
  sessions.
- Streamed JSONL scanning instead of loading entire rollout files into memory.
- Moved usage scans off the UI thread and serialized concurrent scans to avoid cache races.
- Preserved incremental caching; the first project-aware rebuild may take several seconds on a very
  large history, while later refreshes only read appended log data.

Antigravity is not included because it does not expose trustworthy per-project token logs.

## Verification

- `npx tsc --noEmit`
- `npm run build`
- `cargo check`
- `cargo test` (72 tests)
- Real-data benchmark against 3,278 JSONL files / 1.93 GB: 22.1s first rebuild, 185ms warm refresh
- `npm run tauri build -- --target universal-apple-darwin`

## Install

Download `AI.Account.Switcher_0.7.2_universal.dmg` from the release assets and drag the app into
Applications.

The build is not code-signed. On first launch, right-click the app and choose **Open**, or run:

```bash
xattr -cr "/Applications/AI Account Switcher.app"
```
