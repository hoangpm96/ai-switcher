# AI Account Switcher v0.6.2

This hotfix prevents Claude scheduled auto-prime from getting stuck behind macOS folder-permission
prompts during background token refresh and priming.

## What Changed

- Hardened the Claude background prime invocation for Claude Code 2.1.201.
- Added `--exclude-dynamic-system-prompt-sections` so Claude does not gather cwd/env/memory/git
  status context for the one-message background prime.
- Run the Claude background process from the app-owned `.prime-home` directory while keeping
  `CLAUDE_CONFIG_DIR` pointed at the selected account profile.
- This specifically avoids macOS TCC prompts caused by Claude spawning `git` under
  `AI Account Switcher.app`, which could stall the CLI until the auto-prime deadline expired.

## Verification

- `cargo test --manifest-path src-tauri/Cargo.toml`
- `npm run build`
- `npm run tauri build -- --target universal-apple-darwin`

## Install

Download `AI.Account.Switcher_0.6.2_universal.dmg` from the release assets and drag the app into
Applications.

The build is not code-signed. On first launch, right-click the app and choose **Open**, or run:

```bash
xattr -cr "/Applications/AI Account Switcher.app"
```
