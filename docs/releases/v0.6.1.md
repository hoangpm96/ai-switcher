# AI Account Switcher v0.6.1

This release adds visibility into Codex usage-limit reset credits, so each Codex subscription
account can show whether it still has earned resets available and when those reset credits expire.

## What Changed

- Added Codex reset-credit parsing to the live quota reader. The app now reads the summary count
  from Codex usage data and, when available, fetches the detailed reset-credit list with grant and
  expiry timestamps.
- Added a compact reset-credit action to the bottom icon row of each Codex subscription account
  card. The badge shows the available reset count; clicking the icon opens a modal with the detailed
  reset list.
- Accounts with no reset credits now show `0 available` in the modal instead of hiding the reset
  state.
- API/proxy accounts continue to hide reset-credit data because they do not use provider OAuth quota
  endpoints.
- The reset-credit detail fetch is best-effort. A failed detail request does not break the normal
  quota refresh; the app keeps showing the 5-hour and weekly quota data it can read.

## Verification

- `cargo check`
- `cargo test`
- `cargo test quota`
- `npm run build`
- `npm run tauri build -- --target universal-apple-darwin`

## Install

Download `AI.Account.Switcher_0.6.1_universal.dmg` from the release assets and drag the app into
Applications.

The build is not code-signed. On first launch, right-click the app and choose **Open**, or run:

```bash
xattr -cr "/Applications/AI Account Switcher.app"
```
